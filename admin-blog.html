LinkedIn — Publication automatique

Non configuré
Principe : Chaque post marqué "LinkedIn" envoie un webhook Make.com qui publie automatiquement sur la page AYYS GROUP. Configuration unique.
🔗 Webhook LinkedIn
Créez un scénario Make.com, copiez l'URL webhook et collez-la ici.
URL Webhook Make.com — LinkedIn
⚙️ Configuration Make.com — LinkedIn (guide complet)
1
Créer un compte Make.com (gratuit)

Allez sur make.com → créez un compte → cliquez Create a new scenario → nommez-le AYYS → LinkedIn.

2
Module 1 — Déclencheur Webhook

Dans le scénario → cliquez + → recherchez Webhooks → sélectionnez Custom webhook → cliquez Add → nommez-le ayys-linkedin → Make génère une URL unique.

Copiez cette URL et collez-la dans le champ "URL Webhook" ci-dessus → cliquez Enregistrer.

3
Module 2 — Filtre (optionnel mais recommandé)

Après le webhook, cliquez la petite roue crantée entre modules → Set up a filter → condition : li Equal to true. Seuls les posts cochés LinkedIn sont traités.

4
Module 3 — LinkedIn → Create Company Update

Cliquez + → recherchez LinkedIn → sélectionnez Create a Company Update → connectez votre compte via OAuth (fenêtre pop-up LinkedIn).

Sélectionnez la page AYYS GROUP. Mappez les champs :

Commentary → {{1.title}} + saut de ligne + {{1.excerpt}} + 🔗 ayys-group.com

Visibility → PUBLIC

5
Activer et tester

En haut à droite → bouton ON → cliquez Run once pour armer le scénario → puis utilisez le bouton ⚡ Tester la connexion ci-dessous. Make doit afficher une exécution réussie dans l’historique.

📦 Payload JSON envoyé par l’admin
{
  "id": "p1746123456abcd",
  "title": "Le cuivre dépasse 12 000 $/t",
  "excerpt": "Analyse AYYS du marché LME...",
  "cat": "Marchés & prix",
  "date": "2026-05-01",
  "li": true,
  "gba": false,
  "site_url": "https://ayys-group.com/#blog"
}

Dans Make, référencez les champs via {{1.title}}, {{1.excerpt}}, {{1.cat}}, {{1.site_url}} etc.

Google Business — Publication automatique

Non configuré
Résultat visible : Vos posts apparaissent directement sous la fiche "AYYS Commodities" dans Google Maps et Google Search, avec un bouton "En savoir plus" qui renvoie vers votre site.
🔗 Webhook Google Business
Même principe que LinkedIn — un webhook Make.com dédié reçoit le post et le publie sur votre fiche Google vérifiée (AYYS Commodities, Paris).
URL Webhook Make.com — Google Business
⚙️ Guide Make.com — Google Business
1

Créer un 2ème scénario Make.com

Sur make.com → Create a new scenario → nommez-le AYYS → Google Business. Vous pouvez aussi ajouter Google dans le même scénario que LinkedIn en parallèle.

2

Module 1 — Webhook déclencheur

Ajoutez Webhooks → Custom webhook. Copiez l'URL générée et collez-la dans le champ ci-dessus. Chaque canal a sa propre URL unique.

3

Module 2 — Filtre

gba = true — seuls les posts cochés "Google Business" sont relayés.

4

Module 3 — Google My Business → Create a Local Post

Cherchez le module Google My Business → Create a Local Post dans Make. Connectez votre compte Google admin (celui qui gère business.google.com).

Sélectionnez la fiche : AYYS Commodities — Paris

Mappez les champs :

Summary → {{title}} + \n\n + {{excerpt}}

Call to Action Type → LEARN_MORE

Call to Action URL → https://ayys-group.com/#blog

Topic Type → STANDARD (ou EVENT si cat = Événement)

5

Activez le scénario

Bouton ON dans Make. Le post apparaît sur Google sous 5 à 10 minutes. Testez depuis ce panneau.

ℹ️ Comment fonctionne l’affichage ?
✏️
Vous publiez un post dans cet admin

Le post est enregistré dans le localStorage du navigateur — une zone de stockage locale qui persiste entre les sessions.

💾
L’index lit ce même localStorage

La page d’accueil (index.html) charge les posts automatiquement via JavaScript au chargement, et se met à jour en temps réel si un post est ajouté dans un autre onglet.

👁
Affiché immédiatement — sans serveur

Aucun rechargement nécessaire. Les 6 posts les plus récents sont affichés dans la grille. Revenez sur l’onglet du site pour voir la mise à jour instantanée.

✓ Important : Ce système fonctionne sur le même appareil et le même navigateur. Pour un hébergement multi-poste ou collaboratif, exportez votre JSON et importez-le sur chaque poste.
