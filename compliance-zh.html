合规框架

交易层面的
管控整合

AYYS将合规内嵌于每笔交易——不是事后附加的程序层，而是参与的前提条件。我们的框架覆盖KYC、反洗钱、国际制裁、OECD冲突矿产尽职调查和欧盟CBAM。

KYC与反洗钱
FATF 40项建议 / 欧盟AMLD6 / 法国Sapin II

了解您的交易对手 — 完整实际控制人核实

AYYS对所有新交易对手在任何商业讨论开始前均适用强化尽职调查。

  • 法律实体核实——注册文件、公司章程、董事信息
  • 追溯至自然人层级的最终受益人（UBO）识别（门槛：25%）
  • 高风险交易对手的资金来源和财富来源文件
  • 通过商业数据库进行PEP和负面媒体筛查
  • 持续监控——活跃交易对手每年更新
  • 交易监控——标记异常规模和管辖区不匹配
制裁
OFAC（美国）/ 欧盟综合名单 / 联合国安理会 / 英国OFSI / 法国SDFM

任何承诺前的多制度筛查

AYYS在任何交易前，对所有交易对手按照四大制裁制度进行筛查。

  • OFAC SDN名单、行业制裁识别名单及CAATSA指定
  • 欧盟综合金融制裁名单——每日更新
  • 联合国安理会综合制裁名单
  • 英国OFSI综合名单——无论交易货币如何均适用
  • 航运交易须进行船舶、船旗及港口筛查
  • 伊朗原产地交易的二级制裁分析
  • SDN邻近或复杂管辖区风险须上报外部顾问
OECD尽职调查
OECD指南 / 3TG+钴 / 欧盟冲突矿产法规 / Dodd-Frank 1502

冲突矿产 — 五步骤框架

对于所有来自刚果金、赞比亚及其他冲突影响和高风险地区（CAHRAs）的材料，AYYS适用OECD《负责任供应链尽职调查指南》。

  • 步骤一：建立强有力的公司管理体系——内部政策、供应商行为准则、预警机制
  • 步骤二：识别和评估风险——矿山层级的原产地文件记录
  • 步骤三：设计并实施应对已识别风险的策略
  • 步骤四：供应链尽职调查的独立第三方审计——每年对一级供应商实施
  • 步骤五：供应链尽职调查报告——摘要可应委托客户要求提供
  • 适用时对来自刚果金的3T矿产进行iTSCi追踪标记
  • 从矿山到最终交付的监管链文件
欧盟CBAM与贸易文件
法规（EU）2023/956 / UCP 600 / Incoterms 2020

碳边境调节机制与文件完整性

欧盟CBAM适用于进口至欧盟的铜、铝、钢铁等。AYYS可应要求提供嵌入式碳强度数据。所有AYYS交易均按照国际贸易标准进行文件管理。

  • 铜阴极、铜杆和铜精矿的嵌入式CO₂强度报告
  • 协助进口商进行CBAM申报
  • 符合UCP 600的SWIFT MT700信用证
  • 提单（OBL）——3/3正本凭信用证或电汇交单
  • 海运保险——协会货物条款（A），一切险
  • 合同——英国法律，ICC巴黎仲裁
